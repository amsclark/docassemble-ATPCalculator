# Fonts

Two open-licence typefaces, self-hosted so the interview makes no request
to a third-party font server.

| File | Family | Axis | Source |
| --- | --- | --- | --- |
| `public-sans-latin.woff2`, `public-sans-latin-ext.woff2` | Public Sans | variable weight 100-900 | <https://github.com/uswds/public-sans> |
| `source-serif-4-latin.woff2`, `source-serif-4-latin-ext.woff2` | Source Serif 4 | weight 600 | <https://github.com/adobe-fonts/source-serif> |

Both are under the SIL Open Font License 1.1. The licence text is in
`OFL-Public-Sans.txt` and `OFL-Source-Serif-4.txt`.

The subsets are the woff2 files Google Fonts serves, with the same
`unicode-range` values, which `../atp-theme.css` repeats.
